# ClearReposts — массовое снятие репостов TikTok

Два инструмента с общей логикой:

- **`tiktok_repost_cleaner.py`** — скрипт для ПК (Windows). Работает уже сейчас, заодно служит стендом для разведки селекторов.
- **`ios/`** — приложение для iPhone. Логин в TikTok внутри приложения, удаление там же, без компьютера.

## Как это работает

Официального API для удаления репостов у TikTok нет — Login Kit даёт только чтение.
Используется веб-сессия: вход обычной формой, дальше работа идёт в `WKWebView`.

Список репостов TikTok отдаёт на `https://www.tiktok.com/api/repost/item_list/`
(`itemList`, `cursor`, `hasMore`). Дёрнуть его напрямую из `URLSession` нельзя:
из 40 параметров три — анти-бот подписи `X-Bogus`, `X-Gnarly`, `msToken`,
которые генерирует JS самого TikTok.

Поэтому приложение не подделывает подписи, а **перехватывает ответ**: подменяет
`window.fetch` и `XMLHttpRequest` внутри WebView и читает JSON, который страница
запросила сама. Отсюда берутся превью, автор, описание и дата — тот же список,
что показывает ClearTok. Снятие репоста делается кликом по `repost-action-tag`
на странице видео.

Подтверждено на живом аккаунте 21.08.2026: первый элемент ответа совпал
со строкой №1 в интерфейсе ClearTok.

Пароль остаётся внутри WebView и системного хранилища кук — приложение его не видит.

## Сборка .ipa без Mac

> **Не удаляй `.gitignore`.** В `.tt-profile/` лежат куки твоей TikTok-сессии —
> это фактически доступ к аккаунту. `.gitignore` не даёт им попасть в репозиторий.
> Если сессия всё же утекла в публичный репо — смени пароль TikTok и заверши
> все сеансы в настройках безопасности.

1. Создай репозиторий на GitHub и залей туда эту папку:

   ```
   git init
   git add .
   git commit -m "ClearReposts"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/clearreposts.git
   git push -u origin main
   ```

2. Во вкладке **Actions** запустится workflow «Build IPA» (macOS-раннер, бесплатно
   для публичных репозиториев). Через ~5 минут скачай артефакт `ClearReposts-ipa`.

3. Установи на iPhone через **Sideloadly** (есть версия под Windows) со своим Apple ID.
   Бесплатная подпись живёт 7 дней — потом переустановить тем же Sideloadly.

## Как пользоваться приложением

1. Войти в TikTok на первом экране.
2. **Найти репосты** — приложение откроет профиль, пролистает вкладку и соберёт список.
3. **Проверка без удаления** — прогон вхолостую: открывает те же страницы, но не нажимает.
   Убедись, что кнопка находится.
4. **Снять все репосты** — с подтверждением. Можно остановить в любой момент.

## Если ничего не находится

TikTok периодически меняет вёрстку. Когда селектор перестаёт работать, приложение
показывает раздел **«Диагностика: data-e2e на странице»** — это список реальных
атрибутов текущей страницы. Нужный селектор вписывается в **Настройки → Селекторы**
(по одному в строке), пересборка не требуется.

## Капча

TikTok показывает слайдер-пазл («передвиньте ползунок»), когда замечает
автоматизацию. Это проверено на живом аккаунте: в headless-режиме профиль
не открывается вообще — сразу капча.

Оба инструмента её **распознают и останавливаются**, передавая управление тебе:

- в приложении поднимается баннер «Нужна проверка», WebView раскрывается,
  ты проводишь ползунок пальцем и жмёшь «Продолжить»;
- скрипт на ПК пишет в лог и ждёт, пока ты пройдёшь проверку в окне браузера.

Поэтому скрипт нужно запускать **без `--headless`**: в фоновом режиме капчу
пройти физически невозможно.

## Темп и блокировки

Между видео стоит случайная пауза 2.5–5 секунд. Быстрее — риск временного
rate-limit со стороны TikTok. Ниже 2 секунд опускать не стоит.
Автоматизация формально противоречит правилам TikTok; аккаунт и репосты твои,
но риск блокировки действий существует.

## Скрипт для ПК

Это инспектор DOM и сети для приложения, а не самостоятельный продукт:
с айфона посмотреть разметку TikTok нечем, а без неё приложению нечего нажимать.
Заодно умеет чистить репосты с компьютера.

```
python tiktok_repost_cleaner.py login          # войти, сессия сохранится
python tiktok_repost_cleaner.py autoprobe      # разведка селекторов, ник определит сам
python tiktok_repost_cleaner.py probe @ник     # то же, но с ручными шагами
python tiktok_repost_cleaner.py sniff @ник     # перехватить запрос снятия репоста
python tiktok_repost_cleaner.py run @ник --dry-run --limit 3
python tiktok_repost_cleaner.py run @ник       # снять всё
```
